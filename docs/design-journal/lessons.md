# 5단계 피벗이 남긴 교훈

> GameSpec → AdSpec → VPP → Competitor → Hub 5단계 피벗 과정에서 각 단계가 다음 단계로 넘긴 사실과 결정을 정리합니다. 각 교훈은 슈퍼센트 회사 이해(4공백, AI Player 존재, AI 영상 PD 직군 신호 등)와 맞물려 있습니다.

---

슈퍼센트의 'AI 애플리케이션 엔지니어' 과제 수행 과정에서 발생한 5단계 피벗은 **슈퍼센트의 비즈니스 공백에 대한 심층적 이해**와 **기술적 리스크 관리**가 결합하며 최적의 안으로 수렴해가는 과정이었습니다. 각 단계별 교훈과 인과 관계는 다음과 같습니다.

### 1단계: GameSpec AI (게임 아이디어 검증)
*   **핵심 아이디어**: 게임 기획안을 입력하면 시장 적합성을 스코어링하고 GDD를 자동 생성하는 도구.
*   **슈퍼센트 이해**: 하이퍼캐주얼에서 미드코어로 확장 중인 상황에서, 기존의 단순 지표(D1 리텐션 35%)로는 검증하기 어려운 **"재미의 조기 검증 공백"**을 타격하고자 함.
*   **교훈 및 인과 관계**: 단순히 텍스트를 주고받는 구조는 **"프롬프트 래퍼(Wrapper)"**에 불과하여 엔지니어링 역량을 보여주기 부족하다는 비판을 수용함. 이 비판은 다음 단계에서 **정량적 측정 체계(Eval Harness)** 도입의 계기가 됨.

### 2단계: AdSpec AI (광고 소재 브리프 생성)
*   **핵심 아이디어**: 하이브리드 캐주얼 광고 소재의 10가지 A/B 테스트 콘셉트를 생성하는 도구.
*   **슈퍼센트 이해**: 슈퍼센트가 **'AI 영상 PD'** 직군을 신설하여 채용 중이라는 신호를 "광고 소재 기획 단계의 공백"으로 해석하여 정조준함.
*   **교훈 및 인과 관계**: 
    *   **엔지니어링 교훈**: 래퍼 비판을 극복하기 위해 모델의 출력을 스스로 정량 측정하는 **Eval Harness** 4축 체계를 설계하고 실제 배포까지 완료함.
    *   **비용 트라우마**: 개발 과정에서 **$500 규모의 API 비용 폭주**를 경험하며, 런타임 호출 비용을 근본적으로 제어할 아키텍처의 필요성을 통감함.
    *   **실무적 교훈**: 결과물이 텍스트 몇 줄에 그쳐 실제 영상 제작(스토리보드, 편집)으로 이어지는 **다운스트림(downstream) 연결성**이 부족함을 깨달음.

### 3단계: Virtual Playtest Panel (VPP, 가상 플레이테스트)
*   **핵심 아이디어**: 5인의 AI 페르소나가 실제 게임 빌드를 병렬로 플레이하고 감정 타임라인 리포트를 생성하는 시스템.
*   **슈퍼센트 이해**: 빌드 제작 전 "재미"를 검증할 수단이 부재한 병목 지점을 해결하려 함.
*   **교훈 및 인과 관계**: 
    *   **중복 확인**: 9시간의 심층 설계 후 슈퍼센트 사내에 이미 **'AI Player'**라는 유사 도구가 존재함을 확인하고 차별화를 위해 과감히 폐기함.
    *   **기술적 대안**: $500 트라우마 해결을 위해 Anthropic API Key 직접 호출 대신 **Claude Code Max Plan의 'Routines'**를 백엔드 엔진으로 활용하는 'Option Ω' 설계를 도출함.

### 4단계: Competitor Creative Studio (경쟁 광고 분석)
*   **핵심 아이디어**: 경쟁사 광고 URL을 입력하면 멀티모달 오케스트레이션(yt-dlp → ffmpeg → Claude Vision)을 통해 시각적 Hook 요소를 자동 분석하는 도구.
*   **슈퍼센트 이해**: UA 팀이 매주 경쟁사 광고 분석에 소요하는 **"주당 최대 14시간의 반복 업무"**라는 구체적 수치에 기반한 페인 포인트를 타격함.
*   **교훈 및 인과 관계**: 분석 기능은 뛰어나지만, 사내 도구 **'Super Darts'**와 영역이 일부 겹치고 "AI 애플리케이션 엔지니어"라는 직무 본연의 역할(전사 도구 확산 및 오케스트레이션)을 더 메타적으로 보여줄 필요성을 느낌.

### 5단계: AI Tool Request Hub (최종 확정안)
*   **핵심 아이디어**: 전사 구성원의 AI 도구 요청을 받아 Claude Code Routine이 프로토타입을 자동 생성·배포하고 카탈로그에 등록하는 **메타 도구**.
*   **슈퍼센트 이해**: 슈퍼센트 공식 블로그가 명시한 **4대 미해결 과제** 중 **"전사 요청 창구 부재"**와 **"프로토타입 → 정식 도구 성장 흐름 부재"**를 정확히 정조준함.
*   **결정적 정착 이유**: "AI 수트를 만드는 AI 수트"라는 컨셉이 직무 정의와 완벽히 일치하며, 단순 챗봇이 할 수 없는 **Git, Vercel, Routine 연쇄 오케스트레이션**을 통해 엔지니어링 깊이의 최종 증명이 가능해짐.

---
**요약하자면**, 각 피벗은 **"래퍼 탈피(기술)" → "비용 제어(인프라)" → "사내 도구 중복 회피(비즈니스)"**의 과정을 거쳤으며, 최종적으로 **슈퍼센트가 스스로 인정한 공식적인 공백**을 메우는 메타적 솔루션으로 진화했습니다.
