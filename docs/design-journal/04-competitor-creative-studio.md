슈퍼센트 'AI 애플리케이션 엔지니어' 과제 수행 과정에서 논의된 중간 피벗안 **'Competitor Creative Studio'**의 핵심 내용과 최종안으로의 전환 배경은 다음과 같습니다.

### 1. 기획 배경: 실무적 페인포인트와 공백 공략
*   **UA 팀의 과도한 업무 시간**: 슈퍼센트 UA(User Acquisition) 팀이 경쟁사의 광고 크리에이티브를 수동으로 분석하는 데 **주당 최소 6시간에서 최대 14시간**을 소요한다는 실무적 병목 현상을 발견했습니다.
*   **사내 도구와의 차별화**: 기존에 운영 중인 'Super Darts'는 내부 광고 성과 예측에 특화되어 있으나, 외부 경쟁사 광고의 **시각적 요소(Hook, 캐릭터, 연출 등)를 정량적으로 역설계**하는 영역은 여전히 사람의 판단에 의존하는 공백 상태였습니다.

### 2. 기술적 조합: yt-dlp + ffmpeg + Claude Vision
*   **멀티모달 오케스트레이션**: 단순히 텍스트를 입력받아 요약하는 챗봇 수준을 넘어, **yt-dlp(영상 다운로드) → ffmpeg(프레임 추출) → Claude Vision(시각 요인 분석)**으로 이어지는 복합 파이프라인을 구축하고자 했습니다.
*   **구조적 차별화 증명**: 단일 프롬프트 호출로는 재현할 수 없는 **외부 시스템 통합 및 비전 분석 워크플로우**를 통해 엔지니어링 깊이를 증명하고 "프롬프트 래퍼"라는 비판을 피하려 했습니다.

### 3. Claude Code Routines 채택 이유: $500 비용 트라우마 해결
*   **API 비용 폭주 트라우마**: 이전 프로젝트(AdSpec) 테스트 과정에서 **500달러(약 70만 원) 규모의 비용이 청구**된 경험으로 인해 런타임 호출 비용에 대한 강한 거부감이 형성되었습니다.
*   **정액제 백엔드 엔진**: Anthropic API Key를 직접 호출하는 대신, **Claude Code Max Plan의 'Routines'**를 활용하면 월간 구독료 내에서 추가 비용 없이 복합 파이프라인(bash 실행 등)을 실행할 수 있다는 점에 주목했습니다.
*   **비용 리스크 차단**: Routines는 Anthropic 인프라에서 돌아가는 비동기 엔진으로, 개발 및 시연 과정에서의 **비용 리스크를 근본적으로 제거**하면서도 최신 AI 기술 활용 능력을 보여줄 수 있는 선택이었습니다.

### 4. 최종안(AI Tool Request Hub)으로 다시 피벗한 이유
*   **공식적인 미해결 과제 발견**: 슈퍼센트 공식 블로그 조사 중 AI Hub의 **"전사 요청 창구"와 "프로토타입에서 정식 도구로의 성장 흐름"이 아직 해결되지 않은 과제**로 명시된 것을 확인했습니다.
*   **직무 정의와의 완벽한 정렬**: 지원 직무인 'AI 애플리케이션 엔지니어'의 정의가 "구성원을 슈퍼히어로로 만드는 AI 수트를 설계하는 일"인 만큼, 도구를 자동으로 생성·배포하는 **'메타 도구(AI 수트를 만드는 AI 수트)'** 기획이 직무 이해도를 보여주기에 더 강력하다고 판단했습니다.
*   **기존 안의 리스크 회피**: Competitor Creative Studio는 경쟁사 영상 다운로드에 따른 **저작권/약관 리스크**가 있고, 이미 성숙한 사내 도구(Super Darts)와 서사가 겹칠 위험이 있어 더 안전하고 임팩트 있는 'Request Hub'로 최종 수렴하게 되었습니다.
