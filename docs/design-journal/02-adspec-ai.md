> - **"다운스트림 공백"** → 다음 기획은 생성→배포→실행까지 닿는 E2E 설계 필수

---

슈퍼센트의 'AI 애플리케이션 엔지니어' 채용 과제를 위해 도출되었던 두 번째 기획안, **AdSpec AI(광고 소재 브리프 & A/B 콘셉트 생성기)**에 대해 소스 및 대화 기록을 바탕으로 정리해 드립니다.

### 1. 피벗 배경: AI 영상 PD 직군 신설 신호
최초 기획인 'GameSpec AI'에서 AdSpec AI로 전환하게 된 결정적 계기는 슈퍼센트의 최신 채용 공고 분석이었습니다.
*   **신규 직군 발견:** 슈퍼센트가 **'AI 영상 콘텐츠 PD' 및 'AI 영상 크리에이터'** 트랙을 신설하여 채용 중이라는 강한 신호를 확인했습니다.
*   **사내 도구 공백 타겟팅:** 기존 ML 팀은 ROAS 예측(Super Darts) 등 데이터 분석에서 성숙한 상태였으나, **출시 전 광고 소재 기획 단계**는 이제 막 인력이 채워지는 공백 영역으로 판단되었습니다.
*   **실무적 병목 해결:** 영상 PD들이 매일 10~30개의 광고 콘셉트를 수동으로 브레인스토밍하며 하루 2~3시간 이상을 소요하는 병목 지점을 AI로 해결하고자 했습니다.

### 2. 설계 방향 및 핵심 컨셉
AdSpec AI는 단순한 텍스트 생성을 넘어 **"광고 콘셉트 제작 파이프라인의 표준화"**를 목표로 설계되었습니다.
*   **주요 기능:** 게임 이름, 장르, 메카닉, 타겟 페르소나를 입력하면 **10개의 광고 콘셉트**를 생성합니다.
*   **표준화된 출력:** 각 콘셉트에는 **3초 훅 카피, 15초 장면 설명, 6개 앵글 분류(FOMO/유머 등), A/B 테스트 변수(오프닝/CTA/BGM)**가 포함됩니다.
*   **슈퍼센트 DNA 임베딩:** *Pizza Ready, Snake Clash, XP Hero* 등 슈퍼센트 실제 히트작의 성공 패턴을 시스템 프롬프트에 학습시켰습니다.

### 3. 구현 및 배포 결과물
이 프로젝트는 실제 작동하는 수준까지 개발 및 배포가 완료되었습니다.
*   **기술 스택:** Next.js 16, Tailwind CSS, Recharts, Anthropic SDK(Sonnet 4.5)를 사용했습니다.
*   **구현된 컴포넌트:** 입력 폼(`BriefForm`), 6개 앵글 분포 시각화(`DiversityChart`), 10개 콘셉트 그리드(`ConceptCard`) 등이 포함되었습니다.
*   **배포 상태:** Vercel을 통해 **`adspec-ai.vercel.app`** 경로로 실제 배포되어 HTTP 200 정상 접속이 가능했습니다.

### 4. Eval Harness: 4축 평가 체계
"단순 프롬프트 래퍼"라는 비판을 넘어서기 위해 AI 모델의 출력을 정량적으로 측정하는 **Eval Harness**를 설계했습니다.
1.  **Schema Validity (스키마 유효성):** 모델 응답이 정의된 JSON 구조를 100% 만족하는지 측정합니다.
2.  **Coverage Entropy (앵글 다양성):** 생성된 10개 콘셉트가 6개 광고 앵글에 얼마나 고르게 분포하는지 Shannon entropy로 계산합니다.
3.  **Consistency (재현성/일관성):** 동일 입력에 대해 구조적 안정성 및 후크 텍스트의 의미적 다양성을 측정합니다.
4.  **Playable Coverage (도메인 정합성):** 모델이 스스로 Playable Ad 체크리스트 6항목을 얼마나 준수했는지 자가 보고(self-report)하는 지표입니다.

### 5. 500달러 API 비용 폭주 사건
개발 과정에서 발생한 예상치 못한 비용 문제는 이후 프로젝트 방향에 큰 트라우마를 남겼습니다.
*   **발생 과정:** AdSpec의 런타임 테스트 과정에서 API 호출이 누적되어 **Anthropic Console에 500달러(약 70만 원) 규모의 비용**이 청구되었습니다.
*   **원인 분석:** 개발 중 반복적인 테스트 루프와 5인 페르소나 병렬 호출 설계(VPP 확장안 포함) 시 발생할 수 있는 비용 리스크를 사전에 완벽히 제어하지 못한 결과로 분석되었습니다.
*   **영향:** 이 사건 이후 Anthropic API Key를 직접 쓰는 대신 **Claude Code의 Max Plan 'Routines'**를 활용하거나 **BYOK(사용자 키 입력)** 방식을 채택하는 등 비용 중심의 아키텍처 재설계가 이루어졌습니다.

### 6. 폐기 및 전환 사유
완성도 높게 배포되었음에도 불구하고 AdSpec AI가 최종안에서 제외된 이유는 다음과 같습니다.
*   **실무적 효용 한계:** 결과물이 텍스트 몇 줄에 그쳐 스토리보드 제작이나 실제 영상 촬영으로 이어지는 **다운스트림(downstream) 연결성이 부족**하다는 지적을 받았습니다.
*   **사실 전제 오류:** 초기 타겟이었던 "AI 영상 PD" 직군이 나중에 확인된 실제 공고(PO, AI 기획자)와는 직결되지 않음이 밝혀져 전략적 근거가 약화되었습니다.
*   **래퍼(Wrapper) 비판:** 단순히 프롬프트만 잘 짜서 결과를 내놓는 수준은 엔지니어링 깊이를 증명하기에 부족하다는 판단에 따라, 더 복잡한 오케스트레이션이 필요한 과제로 피벗하게 되었습니다.

이후 프로젝트는 **VPP(Virtual Playtest Panel)**를 거쳐 최종적으로는 Routines 백엔드 기반의 **Competitor Creative Studio**로 수렴되었습니다.
