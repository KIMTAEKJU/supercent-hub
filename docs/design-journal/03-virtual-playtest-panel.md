**Virtual Playtest Panel (VPP) Option L**은 슈퍼센트의 콘텐츠 플랫폼 PO가 빌드 제작 전 단계에서 게임의 "재미"를 조기에 검증할 수 있도록 설계된 **AI 페르소나 병렬 플레이테스트 시뮬레이터**입니다.

### 1. 5인 AI 페르소나 구성
서로 다른 성향과 연령대를 가진 5명의 가상 플레이어를 구성하여 게임 반응의 다양성을 확보했습니다:
*   **🧒 김민수 (12세)**: 성급하고 빠른 포기를 하는 학생 (Temperature 0.9).
*   **👩 박지은 (35세)**: 여유롭지만 바쁜 워킹맘 (Temperature 0.7).
*   **🧑‍💻 이현우 (22세)**: 도전적이고 분석적인 게이머 (Temperature 0.5).
*   **👵 최서영 (55세)**: 느리고 신중한 초보자 (Temperature 0.3).
*   **📊 박태준 (28세)**: 패턴을 관찰하는 분석가 (Temperature 0.5).

### 2. 3종 고정 게임 템플릿 및 선정 근거
LLM이 실시간으로 게임 코드를 자동 생성하는 방식의 낮은 성공률(20~60%)을 인정하고, 슈퍼센트의 실제 히트작과 매핑되는 **고정 템플릿** 방식을 채택했습니다:
*   **Cafe Rush**: 손님 주문 맞추기 (시간 압박형) — **Pizza Ready** 계열.
*   **Lane Dodge**: 장애물 피하기 (반응 속도형) — **Snake Clash** 유사.
*   **Combo Match**: 패턴 인식 및 제거 (타이머형) — **XP Hero** 유사.

### 3. 브라우저 내 5 iframe 병렬 구조
Vercel Serverless 환경에서의 Playwright 구동 제약(번들 크기, 실행 시간, 메모리 부족)을 해결하기 위해 고안된 아키텍처입니다:
*   **작동 원리**: 별도의 서버 없이 채점자의 브라우저에서 **5개의 iframe**을 통해 Phaser 게임 인스턴스를 병렬로 로드합니다.
*   **오케스트레이션**: 부모 페이지의 JS가 매 초 5개 게임의 상태(JSON)를 수집하여 Vercel Edge API를 통해 AI 행동을 결정하고 다시 주입합니다.
*   **임팩트**: 채점자가 버튼 클릭 후 60~70초 내에 5명의 AI가 실제로 플레이하는 모습을 **실시간으로 관람**할 수 있습니다.

### 4. 9시간 설계 과정 및 6개 대안 기각 내역
2026-04-19 세션에서 약 **9시간**에 걸친 심층 탐색 루프를 통해 25개 이상의 아이디어를 검증했으며, 다음 6개 주요 대안이 기각되었습니다:
1.  **PlayableForge**: 사용자가 이미 거부한 "광고 영역"에 해당하여 기각.
2.  **Agent Ledger**: 공준식 대표의 "4,500명분 AI" 발언을 오독(에이전트 개수로 착각) 및 AWS 신규 기능과 중복되어 기각.
3.  **Async Spec Relay**: Claude Cowork의 네이티브 기능 및 사내 'Night Coder'와 중복되어 기각.
4.  **AI Game Prototype Generator (α)**: Claude Artifacts 1회 호출로 재현 가능하여 앱으로서의 차별성 부족으로 기각.
5.  **MechanicBreeder**: GA 기반 진화 모델의 학술적 성격 및 로컬 하드웨어 사양(Playwright 100개 병렬) 한계로 기각.
6.  **Virtual Playtest (1차 기각)**: modl.ai 등 강력한 상용 제품 존재 및 LLM 페르소나 신뢰성 학술 반박(ICML 2025)으로 일시 기각되었으나 이후 필터 재정의를 통해 부활했었습니다.

### 5. 폐기 및 최종 피벗 (사내 'AI Player' 발견)
9시간의 설계와 1,279라인 규모의 설계 문서 작성이 완료된 상태였으나, 2026-04-22 세션 중 진행된 추가 리서치에서 **슈퍼센트 사내에 이미 'AI Player'라는 QA 자동화 도구가 운영 중임**이 발견되었습니다. 
*   **폐기 이유**: 기업 내부에 이미 존재하는 도구와 중복되는 기획은 엔지니어의 "새로운 문제를 정의하는 역량"을 증명하기 어렵다는 비판을 수용했습니다.
*   **최종 피벗**: VPP 설계를 과감히 폐기하고, 비용 리스크를 최소화하면서 멀티모달 오케스트레이션 실력을 보여줄 수 있는 **'Competitor Creative Studio'**로 최종 피벗했습니다.
