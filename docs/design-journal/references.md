## 3. VPP 리서치 (기각된 안의 근거)

Virtual Playtest Panel 기획 단계에서 **기술 타당성 검증**을 위해 인용된 자료. 이 자료들이 "이미 상용 제품 존재" + "LLM 페르소나 신뢰성 한계"를 증명해 VPP 폐기 결정으로 이어졌습니다.

### 상용 경쟁 제품

- [modl.ai](https://modl.ai/) — AI agents test your game externally (VPP 원안과 거의 동일 컨셉, 상용화됨)
- Unity Game Simulation — Virtual players for game simulation (슈퍼센트 Unity 사용 중 → 이미 접근 가능)
- WeTest Acorn, Regression Games — Tracxn Gameplay Testing 카테고리의 Seed~Series A 경쟁사들

### 학술 논문 · 포지션 페이퍼

- **ICML 2025 Position Paper**: LLM Social Simulation 5대 난제 — LLM 페르소나 공식 한계 인정
- **arXiv 2505.11795**: LLM 페르소나의 인구통계학적 편향 및 재현성 연구
- **arXiv 2602.18462**: Demographic-conditioned persona의 stereotype 편향
- **arXiv 2602.03545**: LLM 페르소나 error 재분배
- **arXiv 2602.06232 (RuleSmith)**: 멀티 에이전트 기반 게임 밸런싱 검증
- **arXiv 2509.22170 (TITAN)**: LLM을 활용한 게임 QA 자동화
- ACM DL: "LLM-simulated data substantially reduced variance compared to real data" — 5명이 비슷하게 행동할 가능성 지적

### Anthropic 공식 대응

- Computer Use (2024.10~) — Anthropic 이 이미 "AI가 게임 화면 보고 플레이" 공식 지원
- Claude Agent SDK — 게임 화면 분석 기능 내장
